# ServiceNow Enterprise Access Request Management

A ServiceNow application designed to automate and manage enterprise application access requests through a structured approval and fulfillment workflow.

## Project Overview

This project demonstrates an enterprise access request process built using ServiceNow App Engine and Flow Designer.

The application manages access requests from submission through approval, provisioning, notification, and completion.

## Key Features

- Custom Enterprise Access Request application
- Access Request table and module
- Manager approval
- Application owner approval
- Conditional security approval for high-risk applications
- Automated access provisioning task creation
- Approval and fulfillment status tracking
- Email notifications
- Automated request closure
- Flow Designer workflow automation

## Technologies

- ServiceNow
- App Engine Studio
- Flow Designer
- ServiceNow Tables
- Approval Engine
- Task Management
- Notifications
